# Playtests

Notes from team play sessions (Document 06, Section 6; Document 08, Section 3). One file per player per session, named `YYYY-MM-<phase>-<name>.md`, copied from [`TEMPLATE.md`](TEMPLATE.md).

## Phase 1 protocol (about two hours)

1. Sign in at http://localhost:5173 and open your Established game on the default world.
2. Play January to the start of February. Each morning read the briefing; decide at least 20 work items yourself; follow at least five "Why?" links; at month end read the statements.
3. Write notes as you go, under the four headings in the template. Short and blunt is best.

A joint review then turns both sets of notes into changes to the Phase 2 plan (Document 08, Section 4).
